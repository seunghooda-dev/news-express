# 운영 방법

## 처음 실행

```powershell
cd "C:\Users\seung\news summary"
.\scripts\setup.ps1
.\scripts\run_review_app.ps1
```

브라우저에서 `http://127.0.0.1:5000`을 엽니다.

## 매일 쓰는 흐름

1. 홈 화면에서 `수동 재수집`을 눌러 전체 기관을 다시 확인합니다.
2. 자동 수집 상태에서 `수집 완료`와 19개 기관 진행 상태를 확인합니다.
3. `주의 필요` 또는 `기관별 수집 상태`를 먼저 열어 위험 신호가 있는 초안부터 검수합니다.
4. 각 초안을 열어 원문과 초안을 비교하고, 필요하면 Gemini 다듬기 버튼으로 다시 정리합니다.
5. `승인 전 체크`가 모두 통과되었는지 확인합니다.
6. 문제가 없는 초안은 `승인`으로 바꿉니다.

## 상단 메뉴

- `대시보드`: 수집 상태, 기관별 상태, 주의 필요 건수를 확인하는 첫 화면입니다.
- `Gemini 사용량`: 로컬 성공 호출 수와 Google AI Studio 사용량 확인 링크를 보는 화면입니다.
- `초안 검수`: 전체 초안과 승인/반려/주의 필요 필터를 다루는 작업 화면입니다.
- `기사 설정`: Gemini 기사 톤, 길이, 문장 스타일을 조정하는 설정 화면입니다.

승인된 기사는 별도 상단 메뉴 대신 대시보드의 `승인 완료` 카드나 초안 검수 화면의 `승인` 필터에서 확인합니다.

## 검수 우선순위

홈 화면의 `주의 필요`는 아래 신호가 있는 초안을 먼저 모아 보여줍니다.

- 원문 본문이 짧아 기사화 근거가 부족할 수 있는 경우
- 사진뉴스·카드뉴스처럼 본문보다 이미지 설명에 가까운 경우
- 게시일 앞에 담당자명 등 불필요한 문구가 붙어 날짜 확인이 필요한 경우
- 같은 제목이 중복 수집된 경우
- Gemini 메모가 비어 있거나 너무 짧은 경우
- 규칙 기반 또는 AI 오류 후 생성된 초안

목록 화면에서는 `오늘 기사`, `신청·모집`, `행사·교육`, `지원·예산`, `사진·카드뉴스`, `게시일 확인` 필터로 먼저 볼 기사를 좁힐 수 있습니다.

## 기관별 상태

홈 화면의 `기관별 수집 상태`는 19개 기관별 누적 수집 건수, 최근 수집 시간, 최근 제목, 수집량 부족 또는 게시일 확인 필요 여부를 보여줍니다.
특정 기관 카드를 누르면 해당 기관의 검수 대기 기사만 볼 수 있으며, 목록은 게시일 기준 최신순으로 정렬됩니다.

## Gemini 사용량

상단 메뉴의 `Gemini 사용량`은 News Express DB에 저장된 성공 호출을 기준으로 오늘 초안 생성, 오늘 다듬기, 전체 Gemini 생성 건수를 보여줍니다.
무료 key의 정확한 남은 요청 수, 분당 제한, 일일 제한은 Google AI Studio의 `Usage and Limits` 화면에서 확인합니다.
Google 공식 문서상 Gemini API rate limit은 요청/토큰/일일 요청 등 여러 축으로 적용되며, 활성 제한은 AI Studio에서 확인하는 방식입니다.

## 운영 로그

앱은 기본적으로 `data/logs/news_summary.log`에 운영 로그를 남깁니다.
로그에는 서버 시작, 수동 재수집 요청, 기관별 수집 성공/실패, Gemini 모델 실패, 초안 생성 보류, Gemini 다듬기 실패, 승인 기사 내보내기, 웹 예외가 기록됩니다.

로그 파일은 자동으로 회전됩니다.

```text
NEWS_SUMMARY_LOG_DIR=data/logs
NEWS_SUMMARY_LOG_LEVEL=INFO
NEWS_SUMMARY_LOG_MAX_BYTES=2000000
NEWS_SUMMARY_LOG_BACKUP_COUNT=5
```

문제가 발생하면 `data/logs/news_summary.log`에서 가장 최근의 `WARNING` 또는 `ERROR` 줄부터 보면 됩니다.

```powershell
.\scripts\collect_and_draft.ps1
.\.venv\Scripts\python.exe -m news_summary.cli show-drafts
.\.venv\Scripts\python.exe -m news_summary.cli export
```

## 인공지능 API

`.env`에 `GEMINI_API_KEY`를 넣으면 Gemini 기사 초안을 사용할 수 있습니다.

키가 없어도 규칙 기반 초안을 만들기 때문에 수집과 검수 흐름은 그대로 확인할 수 있습니다.
