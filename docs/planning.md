# 기획 메모

## 프로젝트 목표

광주·전남 지역 지자체 홈페이지에서 보도자료를 수집해 방송 뉴스 단신 형태의 기사 초안을 자동 생성한다.

## 기본 프로세스

1. 지자체 보도자료 게시판 또는 구독 피드에서 원문 수집
2. 제목, 본문, 게시일, 원문 주소, 출처 저장
3. 인공지능으로 기사 초안 생성
4. 기자 또는 관리자가 원문과 초안을 비교 검수
5. 승인된 기사만 발행 후보로 이동

## 기본 구현 범위

- 파이썬 명령줄 실행
- 데이터베이스 저장
- 구독 피드 수집기
- 일반 게시판 수집기
- 자료 게시판 수집기
- 인공지능 기반 기사 초안 생성
- API 키가 없을 때의 임시 초안 생성
- 원문 제목과 본문 정밀 검사

## 기사 작성 원칙

- 원문에 없는 사실을 만들지 않는다.
- 숫자, 예산, 날짜, 기관명, 장소는 원문 그대로만 사용한다.
- 홍보성 문구보다 사실 전달을 우선한다.
- 방송 뉴스 단신처럼 짧고 읽기 쉬운 문장으로 쓴다.
- 자동 발행하지 않고 반드시 검수 단계를 둔다.

## 추가로 결정할 사항

- kbc 스타일의 정확한 원고 길이와 톤
- 발행 대상 시스템 또는 파일 형식
- 실행 주기: 수동, 매시간, 매일 오전 등
